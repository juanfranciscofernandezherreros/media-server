Resumen rápido

El proyecto ya no es solo un archivo Compose: está planteado como un servidor multimedia privado con aislamiento de red, documentación operativa y validación automática.

Acceso remoto

Jellyfin por Tailscale

Los usuarios autorizados acceden a Jellyfin por la tailnet. La recomendación es no abrir puertos en el router.

Descargas

Deluge por NordVPN

Deluge comparte la red de Gluetun. Si la VPN cae, Deluge no debería continuar por la ruta normal del host.

Administración

Paneles en localhost

Sonarr, Radarr, Prowlarr, Bazarr, Jellyseerr y Deluge Web UI quedan ligados a 127.0.0.1.

Regla principal: Tailscale para acceso remoto, Gluetun/NordVPN para descargas, localhost para administración y router sin port forwarding.

Arquitectura actual

La arquitectura separa tres límites: usuarios por Tailscale, descargas por Gluetun y administración local. Esto reduce exposición accidental y hace más fácil auditar el sistema.

Acceso de usuarios
Usuario autorizado→Tailscale→Jellyfin :8096→movies/ y tv/
Automatización

Flujo de una película o serie

El flujo recomendado evita configuraciones confusas como deluge:58846. En esta arquitectura Sonarr y Radarr hablan con Deluge mediante gluetun:8112.

Solicitud

Jellyseerr recibe la petición del usuario y la envía a Radarr si es película o a Sonarr si es serie.

Búsqueda

Radarr/Sonarr preguntan a Prowlarr, que consulta los indexadores configurados.

Descarga

Radarr/Sonarr envían el trabajo a Deluge usando Host: gluetun y Port: 8112.

VPN

Deluge sale a Internet por Gluetun y NordVPN. El resto del stack no se enruta por esa VPN.

Importación

Cuando termina, Radarr/Sonarr importan, renombran y mueven el archivo a movies/ o tv/.

Reproducción

Jellyfin escanea la biblioteca y los usuarios autorizados ven el contenido por Tailscale.

Modelo de seguridad

La seguridad del proyecto se basa en mínimos privilegios de red: solo se expone lo necesario, y cada superficie tiene su canal correcto.

Comandos de verificación

Estos comandos son los que usaría después de cambios importantes, reinicios del host o actualizaciones de imágenes.

Diagnóstico automático

powershell -ExecutionPolicy Bypass -File .\scripts\check-stack.ps1

Estado general

docker compose ps
docker compose config --quiet

IP VPN de Gluetun

docker exec gluetun wget -qO- https://ipinfo.io/ip

IP pública del host

curl.exe https://ipinfo.io/ip
Resultado esperado: la IP de Gluetun y la IP del host deben ser distintas si Deluge está saliendo correctamente por NordVPN.
